# NaijaTraffic Watch

NaijaTraffic Watch is a mobile-first traffic and accident tracking app for Nigerian roads. It surfaces road incidents, emergency contacts, commuter tips, and alternate routes for key corridors across Lagos, Abuja, and Port Harcourt.

## Features

- Live traffic and accident incident feed
- Route suggestions for congestion-heavy corridors
- Emergency directory and safety guidance
- Community reporting and verification flow
- Responsive mobile interface for commuters on the move

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Start the app:
   `npm run dev`
3. Open the local app in your browser at the Vite URL shown in the terminal.

## Build for Production

`npm run build`

## Notes

This project is a front-end web app for road intelligence and commuter navigation. It does not require any AI service keys to run locally.
